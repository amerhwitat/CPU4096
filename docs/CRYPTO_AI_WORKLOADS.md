# Crypto AI workloads for CPU4096

The CPU4096 research project can benchmark cryptographic and neural workloads generated by the Python crypto research stack.

Recommended benchmark classes:
- SHA-256/SHA-512/SHA-3 compression loops.
- Keccak permutation and Merkle hashing.
- Modular arithmetic used by public cryptographic test vectors.
- CNN convolution kernels.
- GRU/RNN recurrent kernels.
- PPO environment stepping and inference.

Workloads should use synthetic or public datasets. Private-key recovery from public addresses is not a benchmark target.
