# Apple application

Native SwiftUI/Xcode shell for CPU4096. Wide-register and ISA research logic stays behind a portable service boundary and is not replaced by platform UI code.

Targets: iOS/iPadOS (`iosArm64`, `iosSimulatorArm64`) and macOS. Build/archive/export IPA on macOS with Xcode. Existing C++/Java/Node/Python implementations remain authoritative for their platforms.
