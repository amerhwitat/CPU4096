# CPU4096 Kotlin Mobile

Android implementation of the CPU4096 simulator family. The mobile module is isolated under `kotlin/mobile/` and exposes the wide-register research model without replacing the existing C++, Java, Node.js, or Python implementations.

The UI is a native Kotlin entry point for 4096/8192-bit register experiments and the portfolio 128D state boundary. Future KMP shared logic can expose the same deterministic vectors to iOS.
