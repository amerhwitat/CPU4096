# The Arch Linux Giant 🐉

Arch Linux is a reference model for user control, explicit configuration, modularity, and engineering visibility. It is **not** a dependency of Chimera II OS.

## Philosophy
Arch follows a KISS-oriented philosophy and gives users substantial control over desktop, services, packages, drivers, filesystem layout, and workflow. The engineering lesson for Chimera II is to separate policy from mechanism, expose stable interfaces, document system behavior, and avoid unnecessary coupling.

## Rolling release
Arch uses a rolling-release model. Updates should be applied coherently; partial upgrades are unsupported. Maintenance discipline, backups, recovery knowledge, and attention to project news are important.

## pacman and AUR
`pacman` manages official packages. The Arch User Repository (AUR) is community maintained; users should inspect build recipes such as `PKGBUILD` files before use.

## Gaming and Windows compatibility
Arch can support modern Linux gaming through components such as Steam, Proton, Wine, DXVK, VKD3D-Proton, Vulkan drivers, Lutris, Heroic, and Gamescope. Compatibility is application-specific and depends on drivers, APIs, DRM, anti-cheat, and other platform requirements. Wine and related tools can run many Windows applications but are not a complete Windows replacement.

## Chimera II lesson
Chimera II can borrow the useful engineering spirit—visibility, modularity, explicit configuration, user choice, and strong documentation—without becoming an Arch derivative.
